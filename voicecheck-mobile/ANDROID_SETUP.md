# Установка Android Studio для VOICEcheck Mobile

## Шаг 1: Скачайте Android Studio

https://developer.android.com/studio#downloads

Скачайте версию для Windows (.exe)

## Шаг 2: Установите Android Studio

1. Запустите `android-studio-202X.X.exe` от имени администратора
2. Нажмите "Next"
3. Выберите компоненты:
   - ✅ Android Studio
   - ✅ Android Virtual Device (AVD)
4. Выберите папку установки (можно оставить по умолчанию)
5. Нажмите "Install" и дождитесь окончания установки

## Шаг 3: Первый запуск Android Studio

1. Запустите Android Studio
2. Выберите "Standard" установку
3. Нажмите "Next" и дождитесь загрузки компонентов (SDK, Build Tools и т.д.)
4. Это может занять 10-30 минут в зависимости от скорости интернета

## Шаг 4: Настройка переменных окружения

Откройте "Панель управления" → "Система" → "Дополнительные параметры системы" → "Переменные среды"

Добавьте новую системную переменную:
- Имя: `ANDROID_HOME`
- Значение: `C:\Users\ВашеИмя\AppData\Local\Android\Sdk`

Добавьте в переменную `Path` (для пользователя):
```
%ANDROID_HOME%\platform-tools
%ANDROID_HOME%\tools
%ANDROID_HOME%\emulator
```

## Шаг 5: Создайте виртуальное устройство (эмулятор)

В Android Studio:
1. Tools → Device Manager
2. Нажмите кнопку "+" (Create Device)
3. Выберите телефон (например, Pixel 6)
4. Нажмите "Next"
5. Выберите образ системы (например, Android 13 - API 33)
6. Если образ не скачан - нажмите "Download"
7. Нажмите "Next" → "Finish"

## Шаг 6: Проверьте установку

Откройте НОВОЕ окно терминала (чтобы подхватились новые переменные) и выполните:

```bash
adb version
```

Если видите версию - всё установлено правильно!

## Шаг 7: Запустите VOICEcheck Mobile

В папке проекта `E:\VOICEcheck\voicecheck-mobile`:

```bash
npm run sync
npm run open:android
```

Откроется Android Studio с проектом:
1. Дождитесь Gradle синхронизации
2. Нажмите зелёную кнопку "Play" ▶️ для запуска на эмуляторе
3. Или подключите реальный телефон по USB и включите "Отладка по USB"

## Если что-то не работает

### Gradle не собирается:
- File → Invalidate Caches → Invalidate and Restart

### Эмулятор не запускается:
- Убедитесь, что в BIOS включена виртуализация (VT-x/AMD-V)
- Попробуйте создать эмулятор с меньшим количеством RAM

### "adb devices" не видит телефон:
- Включите "Режим разработчика" (7 тапов по "Номер сборки" в настройках)
- Включите "Отладка по USB"
- Установите драйверы производителя телефона
